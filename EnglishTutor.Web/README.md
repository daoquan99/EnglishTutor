# EnglishTutor Frontend Agent Files

This folder contains Codex/agent instructions for the EnglishTutor frontend.

## Files

```text
AGENTS.md
rules/
skills/
docs/
```

## Recommended Usage

Copy `AGENTS.md` to the root of the frontend repository.

Copy `rules`, `skills`, and `docs` into the frontend repository if you want Codex/agents to use them as project guidance.
