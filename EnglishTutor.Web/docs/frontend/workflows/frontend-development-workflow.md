# Frontend Development Workflow

## Adding a New Page

1. Add route in `src/app`.
2. Add feature component in `src/features`.
3. Add API client and hooks if needed.
4. Add loading/error/empty states.
5. Update route docs.
6. Update feature/workflow docs.
7. Run lint/typecheck/tests.

## Updating an Existing API Flow

1. Read backend API docs.
2. Update feature API client.
3. Update DTO types.
4. Update query/mutation hooks.
5. Update UI states.
6. Update docs.
7. Run validation commands.
