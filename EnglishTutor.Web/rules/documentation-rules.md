# Frontend Documentation Rules

Documentation updates are part of the Definition of Done.

## Required Documentation Areas

```text
docs/frontend/architecture
docs/frontend/routes
docs/frontend/features
docs/frontend/workflows
docs/frontend/design-system
```

## Route Documentation

When adding or changing a route, update:

```text
docs/frontend/routes/routes.md
```

Each route entry should include:

```text
path
route group
auth requirement
purpose
main feature module
loading/error states
related backend APIs
```
