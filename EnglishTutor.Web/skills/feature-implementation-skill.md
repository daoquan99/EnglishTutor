# Skill: Implement a Frontend Feature

Use this skill when adding or updating a frontend feature.

## Steps

1. Inspect existing feature patterns.
2. Identify target route(s).
3. Identify backend API docs.
4. Create or update feature API client.
5. Create or update query/mutation hooks.
6. Create or update Zod schemas.
7. Create or update feature components.
8. Compose components in `src/app`.
9. Add loading, error, empty, and success states.
10. Update documentation.
11. Run lint/typecheck/tests.

## Rules

- Keep page files thin.
- Keep business UI inside features.
- Do not add unrelated UI libraries.
- Do not skip docs.
